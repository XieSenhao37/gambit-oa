## 场景覆盖

- 微信：游玩、餐饮、同月全额退款、跨月全额退款、未支付不纳入。
- 储值：两批不同比例的本金和赠额、跨批次消费、跨店消费、微信＋储值混合支付、跨月原路恢复批次本金；余额 130 元、剩余可分配本金 85 元。
- 月卡：线上购买、第三方验券、总部赠卡、完整 30 天、跨自然月按时长分配、月内无使用暂留、到期补分、整卡未使用归总部、待核验时长。
- 积分：兑换、已开奖抽奖、跨店来源分摊、商品提供店补偿、总部来源未消费积分、待补成本及二次修改资料。
- 月结：统一 0.6% 手续费及免计费渠道、退款冲减、正数／负数／零净额、先报表后确认、跨月继续结算、重复确认、冻结已确认版本。

这是直接写入业务与结算来源记录的流程演练，不会触发真实微信支付、退款、短信、银行转账或抽奖通知，也不代替这些外部接口的联调测试。保留原测试数据，列表和运营汇总会看到 MOCK 门店及订单。
