# OA 列表页

列表页从 `@/components/AdaptiveTable` 引入 `ProTable` 或 `Table`，业务请求、分页、筛选、勾选和操作回调仍使用原来的 Ant Design API。

- 优先给业务重要列明确的像素宽度；普通列默认 160px，名称/内容/备注等默认 240px，操作默认 200px。表头也有最小宽度。
- 横向滚动宽度至少覆盖各个可见列及勾选/展开列的总宽度，不使用一个偏小的固定总宽度挤压剩余列。
- 标题不逐字换行，长内容在已分配的列宽内换行。需要省略正文时同时提供可点击的完整详情，不依赖 hover。
- 平板和触屏上按钮、分页最小高度 44px；工具栏可换行。字段过多时允许表格内部左右滑动。
- 退款页把申请 ID/类型合并，订单标题保留两行；支付/申请/审核时间、完整标题、备注和失败原因放入“详情”。金融操作仍沿用原有确认流程。
- 历史订单、用户、商品、积分、储值、赛事和仪表盘内嵌表格均已接入。新页面请复用这些组件。

验证：`node --test scripts/table-layout.test.cjs`，`npx tsc --noEmit`，`npm run build`。视觉检查覆盖 768/1024/1180px 宽度、长标题、无备注、展开详情、横向滑动和行勾选；不以真实退款验证布局。
